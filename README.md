# Contact Management System

A Java 17 console application for managing contacts in MySQL. The code separates console interaction, business rules, and persistence, with JDBC prepared statements at the DAO boundary.

## Features

- Add, view by ID/phone/email, update, confirm-before-delete, and undo the most recent in-process deletion.
- Paginated contact listing with name, company, city, newest, or oldest sorting.
- Search by name, phone, email, company, city, country, or keyword.
- Favorite management and favorite listing.
- Birthday list for today and the next N days, including year-boundary ranges.
- CSV, TXT, and JSON export; header-based CSV import with row-level validation and duplicate reporting.
- Dashboard counts and recent contacts.
- SQL data backup and validated restore.
- Required fields and phone/email/length/zip validation, database uniqueness constraints, custom exceptions, and Java logging.

The optional bonus proposals for persistent audit history, multi-user authentication, role-based authorization, and field encryption are not implemented. This is a local single-user console program; do not expose it as a network service.

## Technologies

Java 17+, Maven, MySQL 8+, JDBC, MySQL Connector/J, Jackson, a JDK-based CSV codec, JUnit 6, and Mockito.

## Database Setup

1. Install and start MySQL 8 or later.
2. Run the schema, which creates the database/table, constraints, indexes, and sample contacts:

```powershell
Get-Content .\src\main\resources\database\schema.sql | mysql -u root -p
```

3. Configure credentials in the process environment. The defaults are `DB_URL=jdbc:mysql://localhost:3306/contact_management?serverTimezone=UTC`, `DB_USER=root`, and an empty password. Set `DB_PASSWORD` rather than adding secrets to source control:

```powershell
$env:DB_URL = 'jdbc:mysql://localhost:3306/contact_management?serverTimezone=UTC'
$env:DB_USER = 'root'
$env:DB_PASSWORD = 'your-local-password'
```

## Installation and Run

Install JDK 17+ and Maven, then run from the project root:

```powershell
mvn clean test
mvn exec:java
```

The program returns to the menu after each operation and exits with menu option 12. To package without launching:

```powershell
mvn package
```

## Import and Export

CSV import expects a header row with `first_name,last_name,phone,email,address,city,state,country,zip_code,company,job_title,birthday,notes,favorite`. The `id`, `created_at`, and `updated_at` fields are generated by the application/database. Invalid or duplicate rows are reported and skipped.

Exports include all contacts and are UTF-8 files. SQL backup writes contact-table data only. Restore accepts the application's generated `DELETE FROM contacts` and `INSERT INTO contacts` data statements (plus an optional `USE contact_management`); it rejects other SQL. Restore replaces current contact rows, so review the file and confirm only when appropriate. Use trusted backup files only.

## Testing

Tests cover validation, service duplicate/search behavior, dashboard aggregation, and DAO parameter binding. DAO tests use a mocked JDBC connection and do not require MySQL; no live database integration test is currently included.
